## Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure index.html, style.css and script.js
   are in the same folder.
4. Open index.html in a browser, or use the Live Server
   extension in Visual Studio Code.

## Deploy on Vercel

1. Upload the project files to a GitHub repository.
2. Sign in to Vercel.
3. Import the GitHub repository.
4. Select the framework preset as Other, if prompted.
5. Leave the build command and output directory empty
   for this plain static HTML project.
6. Deploy the website.
